# تصميم ربط هاتف العميل واستقبال المكالمات — Sync AI Voice Notifications

> الحالة: **تصميم فقط** (2026-11-07). لا كود خادم، لا حسابات، لا شراء. التنفيذ بعد اختيار المالك للبنية.
> الأولوية: العميل غير التقني لا يحتاج GitHub ولا مفاتيح API ولا إعداد سيرفر ولا تطبيق على الهاتف.

## 2. الربط بالرمز المؤقت (نفس أسلوب ربط التلفاز بحساب)

مبني على OAuth Device Authorization Grant (RFC 8628):

```
Claude (plugin)                     Sync API                         هاتف العميل
 /sync-notify:link ── POST /v1/pair/start ──►  device_code (سري، يبقى في الجهاز)
                     ◄── user_code KX7-42Q + link (صالح 10 دقائق)
 يعرض الرابط والرمز                                          ◄── يفتح الرابط، يكتب الرقم + موافقة
 يستطلع كل 5 ث ── POST /v1/pair/poll ──►     ── مكالمة تحقق "الرمز 4 7 1 9" ──► يكتب الرمز في الصفحة
                     ◄── device_token (مرة واحدة)          الصفحة: "تم الربط"
 يحفظه في ~/.config/sync-notify (0600)
```

- `user_code`: 7 رموز بلا حروف ملتبسة، صالح 10 دقائق، 5 محاولات.
- مكالمة التحقق تثبت أن الرقم ملك العميل **وموافقته** على المكالمات، وتمنع استخدام الخدمة لإزعاج أرقام الآخرين.
  حدود: 3 مكالمات تحقق/رقم/يوم، و5/عنوان IP/يوم.
- `device_token`: 32 بايت عشوائية. الخادم يحفظ **SHA-256 فقط**، فلا يمكن سرقته من قاعدة البيانات.
  صلاحيته الوحيدة: إرسال أحداث لهذا الحساب. لا يقرأ بيانات ولا يغيّر إعدادات.

## 3. الخدمة الخلفية (أبسط ما يكفي)

**المقترح: Cloudflare Worker واحد + قاعدة D1 (SQLite) + مزوّد مكالمات عبر API.** ملف كود واحد تقريبًا.

| المسار | الوظيفة |
|---|---|
| `POST /v1/pair/start`, `/v1/pair/poll` | بدء الربط واستلام الـ token |
| `GET /link`, `POST /link/verify` | صفحة الربط (عربية، RTL، تعمل على الهاتف) |
| `POST /v1/events` | استقبال حدث من الإضافة (Bearer token + Idempotency-Key) |
| `POST /v1/device/pause`, `/resume`, `/unlink` | إيقاف/استئناف/إلغاء من داخل Claude |
| `POST /webhooks/call-status`, `/webhooks/keypress` | حالة المكالمة وضغط زر "9 للإيقاف" — بتوقيع المزوّد |
| `GET /manage` | إدارة: إيقاف، ساعات الهدوء، حذف البيانات (بعد مكالمة تحقق) |

**الجداول:** `accounts` (رقم مشفّر، منطقة زمنية، إعدادات)، `devices` (hash الـ token، الاسم، الحالة)،
`pairings` (مؤقتة)، `events` (مفتاح فريد `device_id+event_id`)، `calls` (الحالة، المدة، التكلفة).

**سياسة الحدث ← المكالمة:**

| نوع الحدث | الافتراضي |
|---|---|
| `task_succeeded` (اختبارات المشروع نجحت، شغّلها الـ hook لا Claude) | مكالمة: "انتهت مهمتك بنجاح وتم التحقق منها" |
| `task_failed` | مكالمة اختيارية (مفعّلة افتراضيًا): "مهمتك لم تكتمل وتحتاج مراجعتك" |
| `task_completed_unverified` | **لا مكالمة** افتراضيًا. إن فعّلها العميل تقول صراحةً "انتهت مهمة **بدون تحقق آلي**" |
| لا claim / سؤال / توقف | لا شيء (لا يصل حدث أصلًا) |

**منع التكرار والحدود (من جهة الخادم، لا يُعتمد على الإضافة):**
- نفس `event_id` من نفس الجهاز = يُقبل مرة واحدة (قيد فريد في القاعدة).
- تجميع: أحداث خلال دقيقتين = مكالمة واحدة ("انتهت 3 مهام").
- حد أقصى: مكالمة كل 5 دقائق، 10 مكالمات/يوم للعميل (قابلة للتعديل)، ساعات هدوء افتراضية 11م–8ص بتوقيته.
- سقف إنفاق عام للخدمة كلها يوميًا وشهريًا: عند بلوغه تتوقف المكالمات وتُسجّل فقط.
- لا إعادة اتصال عند عدم الرد افتراضيًا (نفس سياسة أحمد).

**الرسائل:** قوالب ثابتة مسجّلة مسبقًا (ملف صوت لكل قالب ولغة) تُشغَّل بـ `<Play>`. لا توليد صوت لكل مكالمة،
ولا أسماء مشاريع أو ملخصات في المكالمة افتراضيًا (خصوصية: الملخص قد يحتوي بيانات حساسة).

## 4. حماية المفاتيح والإيقاف وإلغاء الربط

- العميل **لا يملك ولا يرى أي مفتاح API**. مفاتيح مزوّد المكالمات في Worker Secrets فقط.
- token الجهاز: ملف 0600 على جهاز العميل، hash فقط على الخادم، إلغاء فوري لكل جهاز.
- رقم الهاتف: مشفّر AES-GCM بمفتاح في Worker Secrets، ويظهر في الإدارة مقنّعًا (`+20 10•• ••• •42`).
- Webhooks المزوّد: التحقق من التوقيع (مثل `X-Twilio-Signature`) وإلا تُرفض.
- **طرق الإيقاف (كلها بلا معرفة تقنية):**
  1. أثناء أي مكالمة: "للإيقاف اضغط 9" ← إيقاف فوري لكل المكالمات.
  2. داخل Claude: `/sync-notify:pause` و `/sync-notify:resume`.
  3. داخل Claude: `/sync-notify:unlink` ← يلغي الـ token على الخادم ويحذفه محليًا.
  4. صفحة الإدارة: إيقاف، ساعات الهدوء، **حذف كل بياناتي** (حذف فعلي للرقم والسجل).
  5. حذف الإضافة نفسها يوقف الإرسال تلقائيًا.

## 6. التكاليف الحقيقية لمزوّدي المكالمات (أسعار منشورة، تُراجع قبل القرار)

تُحسب المكالمة **بالدقيقة مقرّبة لأعلى**: إشعار 20 ثانية = دقيقة كاملة.

| الوجهة (موبايل) | Twilio | Plivo |
|---|---|---|
| مصر | ~$0.209/دقيقة | ~$0.191/دقيقة |
| السعودية | ~$0.312/دقيقة | — |
| الإمارات | ~$0.30/دقيقة | ~$0.266/دقيقة |
| أمريكا | ~$0.013–0.014/دقيقة | — |
| رقم المتصل (Caller ID) أمريكي | $1.15/شهر | مشابه |

Telnyx: رسوم $0.002/دقيقة + سعر الوجهة (لم يُؤكَّد سعر مصر بعد).

**مثال عميل في مصر:** 5 مهام/يوم × 30 يومًا = 150 مكالمة ≈ **$31/شهر** على Twilio. أمريكا: ≈ $2/شهر.
النتيجة: المكالمات للشرق الأوسط **غالية**، فيجب أن يكون التسعير بحدّ مكالمات شهري (مثلًا 60 مكالمة ضمن الاشتراك) مع التجميع.

**التجربة المجانية:** Twilio Trial — رصيد ~$15 بلا بطاقة، 30 يومًا، مكالمات إلى **أرقام متحقق منها فقط (حتى 5)**،
وتُشغّل رسالة "حساب تجريبي" قبل المكالمة. يكفي ~70 مكالمة تجريبية لمصر — مناسب لاختبار المالك فقط، لا للعملاء.

**مخاطر يجب اختبارها قبل البيع:** ظهور رقم أجنبي للعميل المصري، وحجب/تصنيف المكالمات الدولية كإزعاج لدى بعض الشبكات.

## 7. ما يبقى كما هو (آلية التحقق)

الإضافة لا تتغير منطقيًا: النجاح المؤكد = `task_succeeded` فقط (اختبارات المشروع يشغّلها الـ hook ونجحت).
`task_completed_unverified` لا يُعلن أبدًا كنجاح مؤكد، وتوقف Claude ليس دليلًا على شيء.
الإضافة تضيف فقط أوامر: `link`, `status`, `pause`, `resume`, `unlink`, `test-call`.
